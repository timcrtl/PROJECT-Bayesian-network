# Réseaux bayésiens en maternité · Bayesian networks in maternity care

## Français

Le projet étudie comment les réseaux bayésiens peuvent éclairer les échanges entre les professionnels de santé et les futurs parents sur les événements liés à l’accouchement.

Le rendu final comprendra un **prototype Python reproductible** qui apprend les probabilités conditionnelles à partir d’observations et actualise les estimations lorsque de nouvelles informations sont disponibles. Un **rapport accessible aux non-spécialistes** expliquera le modèle, les résultats de l’évaluation et leurs limites.

## English

This project explores how Bayesian networks can inform discussions between healthcare professionals and expectant parents about events related to childbirth.

The final submission will include a **reproducible Python prototype** that learns conditional probabilities from observations and updates estimates as new information becomes available. A **report for non-specialists** will explain the model, the evaluation results, and their limitations.
